# Browsers and phones

| Feature | Chrome, Edge (computer) | Safari, iPhone, Firefox |
| --- | --- | --- |
| Timer, notes, tasks, reports | yes | yes |
| Offline | yes | yes |
| Pairing by code or QR | yes | yes |
| Backup to a folder | yes | no: use **Download backup** |
| Mirror to a folder | yes | no: says it is not available |

Why no folders: Safari and Firefox do not let a web page write to a folder you pick.
Download a backup file regularly instead (Settings › Backup & restore).

## iPhone and iPad

- Open the site in Safari and use **Share › Add to Home Screen** to get an app icon.
  The home-screen app keeps its own storage, separate from Safari: set it up again there (join with a code, or restore a backup).
- Safari may clear a site's data after weeks without a visit when the site is not on the home screen.
  Keep a downloaded backup.
- iOS pauses a page in the background.
  A running timer keeps its start time and is correct on return, but syncing resumes only when you reopen the app.
- Scanning a QR code asks for camera permission.
  If you decline, paste the code instead.
